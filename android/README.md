# Plantillado (Android)

Proyecto base (Kotlin + Jetpack Compose) listo para abrir en Android Studio.

## Abrir y emular (sin errores de estructura)

1. En Android Studio: **File → Open**
2. Selecciona la carpeta `android/` (no selecciones `app/`).
3. Espera a que termine **Gradle Sync**.
4. Ejecuta en emulador o tu celular: **Run ▶ (Debug)**.

## Requisitos en tu PC

- Android Studio actualizado
- Android SDK instalado
- JDK 17 (Android Studio ya lo incluye normalmente)
